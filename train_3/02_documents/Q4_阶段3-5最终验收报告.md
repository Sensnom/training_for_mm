# 第7题 第4问：阶段3—5最终验收报告

## 1. 最终结论

在中心独立均匀、A 方向各向同性、A/B 相互独立，以及题面真实越界片段三维回迁、同一 physical ID 保持不变的模型口径下，第4问全局最优方案为

\[
(N_A^*,N_B^*)=(0,57).
\]

最小成本为

\[
C_{\min}=0.095504416669\ \text{元},
\]

B 型介质填充体积分数为

\[
\Phi_B=0.191008833338\%.
\]

## 2. 阶段3：整数全局最优性证明

纯 A 解析最小自短路可行数为 8，成本 0.118752202306 元；纯 B 解析最小自短路可行数为 57，成本 0.095504416669 元，因此用 (0,57) 更新成本上界。

所有成本严格低于该上界的整数方案均满足 N_A<=6。按固定 N_A 下导通概率对 N_B 单调不减，只需检查七个成本支配前沿点：

(0,56), (1,48), (2,39), (3,30), (4,21), (5,12), (6,3)。

七点的总导通概率必要事件解析上界分别为：

0.898341781, 0.894971522, 0.886968280, 0.878355684, 0.869087377, 0.859113481, 0.848380328，均小于 0.90。

另对全部 216 个成本严格更低的整数点进行独立枚举，最大解析上界仍为 (0,56) 的 0.898341781388 < 0.90。因此 (0,57) 为整数空间全局最低成本可行方案。

## 3. 阶段4：严格几何解析公式的数值交叉验证

每个方案使用 M=1,000,000。A 的 X 向半宽严格采用平端圆柱

\[
h_x=\frac{L_A}{2}|u_x|+r_A\sqrt{1-u_x^2},
\]

不使用胶囊体 A 的全图近似。Monte Carlo 同时验证“至少一根直接 X 跨界”的解析下界，以及“直接跨界或同时存在左右电极锚点”的必要事件解析上界。

所有八个方案的 Monte Carlo 结果与解析公式一致；(0,57) 解析下界超过 0.90，七个更便宜前沿点解析上界均低于 0.90。
