# 核心 P0 判定：原题究竟是什么边界？

## 1. 越界规则适用于 X、Y、Z 三个方向

原题第 5 页写的是：

> “当导电介质的任一部分超出微构体边界时……”

随后不是说“只处理非电极方向”，而是：

> “将超出部分沿某一越界方向的反方向平移一个微构体边长，使其由相对侧边界重新进入微构体。”

图 2 随即直接给出了 **X 方向越界**的具体数值例子：

[
x:6000\rightarrow -4000.
]

题面之后继续说明：

> “若平移后的 (X\_1) 仍在 Y 轴或 Z 轴方向超出边界，则重复上述操作即可。”

因此，书面题面支持的结论是：

[
\boxed{\text{X、Y、Z 任一方向发生真实几何越界，都执行回迁。}}
]

而没有任何原题句子可以推出：

[
\boxed{\text{X 开边界，Y/Z 周期。}}
]

题面第 3 页只规定**电极**位于垂直 X 轴的左右两面，并不等价于 X 方向不执行边界截断规则。

所以：

**“X 开、Y/Z 周期”不是题面解释，而是对原题的额外改模。**

目前没有找到能够独立验证的老师原始反馈来覆盖这一结论。

---

## 2. 题面支持的是“实际越界片段回迁”，不是“所有对象的全局最小镜像”

这一点必须与上一个问题分开。

考虑两个不同介质 (A\_i,A\_j)：

- (A\_i) 完全位于 (y=+4990) 一带，并**没有**越过 (+5000)；
- (A\_j) 完全位于 (y=-4990) 一带，并**没有**越过 (-5000)。

按书面题面：

- 两者都没有“超出部分”；
- 因而没有任何几何片段被平移；
- 两者之间应计算处理后的实际域内实体距离。

题面没有说：

> “只要位于相对边界附近，任意两个对象都视为周期邻居。”

所以，将二者直接通过

[
\min\_{k\_y\in{-1,0,1}}
d(A\_i,A\_j+k\_yL\mathbf e\_y)
]

判成相邻，是额外引入了**无限周期复制空间**。

严格题面更接近：

[
\boxed{\text{先切分真实越界实体并回迁，再在基本盒中对回迁后的真实片段计算距离。}}
]

因此用户给出的两种模型中：

[
\boxed{\text{题面支持模型 1，而不是模型 2。}}
]

项目早期自己的 baseline 实际也曾明确意识到这一点：只对真实越界部分执行回迁规则，且“未越界的独立介质之间仍按微构体内真实欧氏距离判定”，不能把边界规则改写成任意对象的最小镜像。

---

## 3. 同一根 A 跨 X 后是否直接形成跨电极通路？

答案是：

[
\boxed{\text{按书面题面逻辑，是。}}
]

严格逻辑链如下。

第一步，原题图 2 中，一根介质 A 的越界部分经过平移后，蓝色实线部分和红色虚线部分仍统一称为：

> “介质 A”。

题面没有将其定义成两个新介质。

第二步，假设其从 (x=+5000) 越出。

则未经移动的域内部分在交界处达到

[
x=+5000,
]

所以该物理介质与右电极实体距离为 0。

第三步，其越界部分沿 X 负方向移动 (L=10000) nm，从

[
x=+5000
]

的切口对应到

[
x=-5000,
]

因此回迁片段同样在左面起始，介质与左电极距离也为 0。

第四步，题面规定：

> 当介质 m 与已带电介质/带电表面满足距离条件时，m 由于极化作用也**全部带电**。

因此不能把同一介质内部的不同片段分别设为不同电状态。

于是图中同一个物理节点 (A\_i) 同时具有

[
(E\_L,A\_i),\qquad(A\_i,E\_R)
]

两条图边。

因此存在长度为 2 的完整通路：

[
\boxed{E\_L\rightarrow A\_i\rightarrow E\_R}.
]

**“这样会使题目退化”不是删除这条机制的合法理由。**

当前报告本身已经计算过该现象，并因为它导致阈值过低而把全周期方案降级为“反例”。 但在不存在教师正式覆盖性澄清的情况下，题面优先级高于“结果看起来是否合理”。

# 解析 sanity check：单根 A 的 X 跨界概率

以下计算严格按照用户要求，只是**发现量级冲突的解析检查**，绝不作为 Q3 最终答案。

设：

[
L=10000\ {\rm nm},\qquad
\ell=5000\ {\rm nm}.
]

圆柱中心的 X 坐标均匀分布于

[
[-L/2,L/2],
]

方向各向同性。

令

[
q=|u\_x|.
]

对各向同性无向轴，

[
q\sim U(0,1).
]

## 只考虑轴线长度

固定 (q) 时，轴线在 X 方向的半投影为

[
a(q)=\frac{\ell}{2}q.
]

只要圆柱中心距左面或右面的距离小于 (a(q))，轴线就发生 X 越界。

条件跨界概率为

# [ P(\text{X-cross}\mid q)

# \frac{2a(q)}{L}

\frac{\ell}{L}q.
]

对 (q) 积分：

# [ p\_\times

# \frac{\ell}{L}E[q]

# \frac{5000}{10000}\times\frac12

0.25.
]

所以报告中“**单根约 0.25**”的轴线级量级判断是正确的。

N 根相互独立时，至少一根 X 跨界：

# [ P\_N

# 1-(1-p\_\times)^N

1-0.75^N.
]

于是：

[
P\_8=0.899887\ldots,
]

略低于 90%，而

[
P\_9=0.924915\ldots.
]

所以：

[
\boxed{\text{轴线近似下“约 9 根达到 90%”完全合理。}}
]

这验证的是报告所谓“退化现象”的**数学量级确实存在**，并不是仿真程序偶然错误。

---

## 加入圆柱半径 30 nm

对于严格平端圆柱，其 X 向最大半宽为

# [ h\_x(q)

\frac{\ell}{2}q
\+
r\_A\sqrt{1-q^2}.
]

因此

# [ p\_\times

\frac{2E[h\_x]}{L}.
]

利用

# [ E[q]=\frac12,\qquad E[\sqrt{1-q^2}]

# \int\_0^1\sqrt{1-q^2},dq

\frac{\pi}{4},
]

得到

# [ p\_\times

\frac{\ell}{2L}
\+
\frac{\pi r\_A}{2L}.
]

代入 (r\_A=30) nm：

[
p\_\times
\approx
0.25471.
]

因此半径只把单根概率从约 25.0% 修正到约 25.5%，**不改变量级结论**，但会使临界整数进一步敏感。

### 1.8 nm 接触阈值是否应再加进去？

对于“是否执行回迁”，答案是**不应直接加**。

原题触发回迁的条件是：

[
\text{实体超出边界},
]

不是

[
\text{距边界}\le1.8\ {\rm nm}.
]

因此 (\delta=1.8) nm 会影响**电极接触和介质间接触**，但不应改变“是否越界并产生对侧片段”的几何事件。

## 对当前 Q2 数量级的 sanity check

题目 0.50% A 填充量对应约 354 根 A，这一换算本身没有问题。

如果暂时采用“中心均匀 + 各向同性 + 相互独立”这三个假设，仅考虑单根 X 跨界事件，就已经有

# [ P(\text{导通}) \ge 1-(1-0.25)^{354}

1-0.75^{354}.
]

其中

[
0.75^{354}<10^{-44}.
]

所以在这组**假设性 sanity check** 下：

[
\boxed{\text{0.50% 对应的数百根 A 已会使导通概率实际上贴近 1。}}
]

0.60%、0.70%、1.00% 的根数更多，同理。

这不是 Q2 的正式答案，因为题面没有规定随机分布；但它足以证明：

> **如果继续采用报告中的“中心均匀 + 各向同性 + 独立”随机生成器，同时严格执行书面 X 回绕规则，那么当前以数百根 A 才到达约 90% 的 Q2/Q3 数值体系不可能继续成立。**

# C. 严格题面边界的可执行规格

下面给出的只是**边界与连通几何内核规格**。随机生成分布仍保持为外部参数，不在本轮擅自确定。

设微构体基本域

[
D=[-L/2,L/2]^3,\qquad L=10000{\rm\ nm},
]

左右电极为

[
E\_L={x=-L/2}\cap D,\qquad
E\_R={x=L/2}\cap D.
]

接触间隔

[
\delta=1.8{\rm\ nm}.
]

## C.1 单根物理介质

每一个真实介质具有**唯一 physical\_id**。

### A 型

未经边界处理的直圆柱定义为

# [ \mathcal C\_i

\left{
c\_i+s u\_i+v:
-\frac{\ell\_A}{2}\le s\le\frac{\ell\_A}{2},
\quad
v\perp u\_i,\quad
|v|\le r\_A
\right},
]

其中

[
\ell\_A=5000{\rm\ nm},\qquad r\_A=30{\rm\ nm}.
]

### B 型

# [ \mathcal B\_i

{x:|x-c\_i|\le r\_B},
\qquad
r\_B=200{\rm\ nm}.
]

对于 Q2–Q4，((c\_i,u\_i)) 或 (c\_i) 从一个**外部传入的概率模型**生成。

本轮不固定该概率模型。

---

## C.2 越界切分与回迁

对任意物理对象 (\mathcal O\_i)，定义其所有基本域内重入片段：

# [ P\_{i,k}

\bigl(
\mathcal O\_i\cap(D+kL)
\bigr)-kL,
\qquad
k\in\mathbb Z^3,
]

只保留非空片段。

这一数学定义等价于：

```
对物理介质 i：
    建立完整原始几何 O_i
    找出 O_i 越过 x/y/z 各边界的部分
    对每个越界片段：
        沿对应方向平移 ±L
        若移动后仍在其他方向越界：
            继续平移
    直到所有片段位于 D 内

```

关键约束：

[
\boxed{\text{所有 }P\_{i,k}\text{ 共享同一个 physical\_id=i。}}
]

绝不能因为在基本盒内成为两个或多个不相连片段而创建多个导电节点。

---

## C.3 不得额外生成全局周期镜像

完成上述处理后：

# [ \mathcal W\_i

\bigcup\_k P\_{i,k}
\subset D.
]

此后所有几何距离均在基本盒 D 中对这些**真实存在的重入片段**计算。

对于两个不同介质 (i\neq j)：

# [ d\_{ij}

\min\_{P\subset\mathcal W\_i,;Q\subset\mathcal W\_j}
\operatorname{dist}(P,Q).
]

不得再额外计算

[
\min\_{n\in\mathbb Z^3}
\operatorname{dist}(\mathcal W\_i,\mathcal W\_j+nL),
]

因为那会再次人为复制所有未越界介质。

即：

[
\boxed{\text{先重入，再普通欧氏距离；不是先保留对象，再全局最小镜像。}}
]

---

## C.4 介质—电极接触

定义

# [ d\_{iL}

\min\_{P\subset\mathcal W\_i}
\operatorname{dist}(P,E\_L),
]

# [ d\_{iR}

\min\_{P\subset\mathcal W\_i}
\operatorname{dist}(P,E\_R).
]

若

[
d\_{iL}\le\delta,
]

则添加

[
(E\_L,i).
]

若

[
d\_{iR}\le\delta,
]

则添加

[
(i,E\_R).
]

**允许同一节点 i 同时具有左右两条电极边。**

---

## C.5 介质—介质接触

对于

[
i\neq j,
]

若

[
d\_{ij}\le\delta,
]

添加无向边

[
(i,j).
]

同一个 physical\_id 的多个重入片段不需要相互“配对”或添加接触边：

[
\boxed{\text{它们从建图开始就是同一个节点。}}
]

## C.6 连通图

建立

[
G=(V,E),
]

其中

[

{E\_L,E\_R}
\cup
{1,\ldots,N\_A+N\_B}.
]

注意：

[
\text{节点数}=\text{物理介质数}+2,
]

而不是“域内片段数+2”。

微构体导通当且仅当

[
E\_L\leftrightarrow E\_R
]

在 G 中连通。

可以使用 BFS、DFS 或并查集。

## D.4 Q4

Q4 有两个不同层级的问题。

### 一级阻塞：边界模型已经失效

所以：

[
(528,0),\qquad C\approx7.8376
]

不得继续作为正式答案。

尤其是严格书面边界对 B 同样适用。球体如果越过 X 边界，其回迁部分仍属于同一个 B 节点，也可能形成同节点两电极接触机制。由于 B 的成本结构又与 A 完全不同，**现有“A 主导、B 不进入最优解”的局部结论没有保留资格。**

本轮不进一步计算新的 Q4 最优数值。

### 二级阻塞：574 点扫描本身也不能证明整数全局最优

当前扫描：

[
N\_A=400,410,\ldots,520,528,
]

[
N\_B=0,50,100,\ldots,2000.
]

报告以此为主证据判断 ((528,0)) 最优。

单粒子成本约为

[
c\_A=0.0148440,
\qquad
c\_B=0.0016755,
]

所以

[
\frac{c\_A}{c\_B}\approx8.859.
]

因此在旧模型下，严格比 ((528,0)) 便宜的整数候选包括：

[
(527,1),(527,2),\ldots,(527,8),
]

以及

[
(526,1),\ldots,(526,17),
]

等等。

这些点一个都不在 (N\_B) 步长 50 的扫描中。

例如：

[
C(527,8)\<C(528,0),
]

而

[
C(527,9)>C(528,0).
]

因此 ((527,1\sim8)) 正是必须被逐点排除的成本支配候选。

报告利用若干较远候选估计“1 个 A 大约需要 10–12.5 个 B 替代”，但这个只是经验局部斜率：

- 不构成对整个整数可行域的下界证明；
- 无法排除靠近 (N\_B=0) 的小整数非线性；
- 也无法证明可靠性边界在所有区段都具有相同斜率。

所以即使边界模型完全不改：

[
\boxed{\text{当前 574 点扫描也不足以证明整数空间全局最优。}}
]
